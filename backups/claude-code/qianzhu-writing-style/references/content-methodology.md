# Content Methodology

## 内容主线

千逐的公众号内容，优先围绕这四条线展开：

### 1. AI 工具、开源项目、效率工具推荐

- 只推荐自己看过、试过、愿意负责的东西
- 重点不是“有个新工具”，而是“它为什么值得你现在花时间”
- 要写适用人群、使用门槛、真实限制

### 2. 工作流和实践方法

- 不只告诉读者工具名，而是告诉他事情怎么做顺
- 比起堆功能，更重视链路、步骤、决策点、踩坑点
- 要让读者看到“方法是怎么长出来的”

### 3. AI 产品与技术趋势的个人观察

- 写 OpenAI、Anthropic、Agent、AI Coding、产品方向都可以
- 但要尽量用更容易理解的方式表达，不写成行业报告
- 重点不是预测一切，而是给出自己的判断和观察框架
- 这里的“趋势”不只来自大新闻，也可以来自一个很小的互联网现象、刷屏梗、校园日常或社交动作
- 小现象不是降级题材，反而常常是最好的真实样本

### 4. 个人成长中的真实记录

- 不是纯日记，也不是硬凹人生感悟
- 要记录理解的变化、判断的建立、试错后的修正
- 让这个号更像一个人，而不是一个内容机器

### 5. 平常事物里的深度洞察

- 可以从一个看似很小、很轻、很互联网的东西切进去
- 比如一个测试、一张梗图、一种校园社交动作、一个流行说法、一个大家没太当回事的小变化
- 重点不是“这个东西很怪”，而是“它为什么值得认真拆”
- 要从小现象里提炼出更稳的结构判断：传播、人性、产品、关系、文化模板

## 双线写法

这是这个 skill 里最重要的方法论之一。

一篇好的千逐文章，通常同时有两条线：

### 价值线

读者看完之后，至少拿走其中一种：

- 一个值得试的工具
- 一套可迁移的方法
- 一个更清楚的判断
- 一个可以少踩坑的经验

### 成长线

读者看完之后，也会看到作者身上的一种变化：

- 我原来怎么理解这件事
- 我后来为什么改了想法
- 我在哪一步踩坑了
- 我现在建立起了什么新的直觉

如果只剩价值线，这篇会有用，但不容易留下作者。

如果只剩成长线，这篇会真实，但容易失去传播和复用价值。

## 四种常用文章结构

### A. 工具 / 开源推荐

1. 用一个具体任务或痛点开头
2. 介绍我为什么会去找这个工具
3. 讲清它解决什么、适合谁、不适合谁
4. 说清使用门槛和真实缺点
5. 给出一句自己的长期判断

### B. 工作流 / 方法实践

1. 从一个总是卡住的环节切入
2. 展示我怎么把事情拆开、接起来、跑通
3. 把关键步骤和选择理由讲清楚
4. 明说踩坑点、失败点和适用边界
5. 收束成一个别人也能迁移的方法

### C. 趋势 / 产品观察

1. 先给一个最近的触发事件或新变化
2. 不急着下宏大结论，先讲我看见了什么
3. 往下拆一层，解释背后的方向变化
4. 给出 1-3 个真正值得记住的判断
5. 最后落到“普通人现在该怎么看、怎么动”

### D. 平常事物洞察 / 互联网文化观察

1. 从一个大家最近都刷到、但很少认真拆的小现象切入
2. 先承认它表面上的轻和荒诞，不要假装它一开始就很宏大
3. 往下拆它为什么会发生，背后是哪层结构在起作用
4. 提炼 1-3 个可以迁移的判断，不要只停在“有意思”
5. 结尾落到一个更具体的提醒，像钉子一样收住，不要滑回礼貌收尾

### E. 成长 / 阶段记录

1. 用一个具体阶段困惑切入
2. 讲清当时的卡点和旧理解
3. 说这段时间是什么事情让判断变了
4. 给出这次变化带来的新行动
5. 用一个不过度煽情的句子收尾

## 比例建议

- 工具、工作流、趋势类文章里，成长线占 10% 到 30% 就够
- 成长记录类文章里，价值线最好也保留 20% 到 40%

不要两个极端：

- 全篇像教程，作者毫无痕迹
- 全篇像心情随笔，读者拿不走东西

## 文章开头怎么定

优先从下面几种入口开始：

- 一个真实任务
- 一个最近踩到的问题
- 一个让我停下来想一会儿的新变化
- 一个我自己也在摸索的困惑
- 一个看起来很小、但让我意识到“这里面有结构”的日常触发点

不要这样开：

- 大而空的时代判断
- 过于完整的定义
- 像行业报告那样的背景铺陈

## 文章中段怎么推进

中段最重要的不是“面面俱到”，而是推进感。

可以反复用这三步：

1. 讲眼前这件事
2. 抽出判断
3. 再回到人和具体场景

这样文章既不会飘，也不会只停留在经验流水账。

## 文章结尾怎么收

更适合的收法是：

- 我现在的理解是……
- 这也是我最近真正建立起来的直觉
- 这件事我还没完全想透，但至少先想清楚了一步
- 而是一个更具体的提醒：……

不适合的收法是：

- 强行升华
- 过度励志
- 把自己写得像已经完成了一轮人生总结
- 在已经有判断之后，又追加“欢迎交流”“以后还会继续写”这类弱化力度的礼貌尾巴
