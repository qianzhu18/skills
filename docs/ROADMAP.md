# Product Roadmap

这个项目的目标不是再做一个“技能商城”，而是做一个能管理本地已安装 skills 的 Web 控制台。

## 产品目标

- 统一查看 `.claude/skills` 和 `.codex/skills`
- 做本地搜索、筛选、排序、分页和预览
- 支持删除、跨库同步、云端镜像同步
- 检查本地与 GitHub 仓库之间是否有差异
- 用 Docker 封装，别人拉仓库后能直接挂载自己的 skills 目录使用

## 暂不优先

- 大而全的公共技能商城
- 复杂的登录系统或多用户体系
- 在线编辑器和富文本后台
- 非 Claude / Codex 的大量额外适配

## 需求评估

### MVP 必须完成

1. `Claude` 与 `Codex` 两个本地技能库独立显示
2. 首页能看到每个库的技能数量、差异数量、待同步数量
3. 技能列表支持搜索、排序、分页
4. 技能详情支持 `SKILL.md`、README、文件列表、版本信息预览
5. 支持删除本地 skill
6. 支持把 skill 从 `Claude` 同步到 `Codex`，或反向同步
7. 支持把 skill 同步到 GitHub 仓库作为云端镜像
8. 支持检查云端镜像是否落后于本地
9. 支持 Docker 本地启动，默认端口 `3009`

### 二期增强

1. 外部 skill 搜索聚合
2. 基于 `skills.sh` / Vercel skills 生态的远端发现能力
3. 一键从远端目录导入到本地
4. 标签、分类、收藏、最近更新
5. 定时检查远端更新

### 开源前必须补齐

1. 首次启动向导
2. 可视化路径配置，避免写死 `/Users/...`
3. Docker 健康检查与更稳的启动流程
4. Windows / Linux / macOS 路径兼容
5. 核心扫描逻辑的测试用例
6. 开源 README、截图、示例配置、贡献指南

## 推荐集成的外部参考

- `openai/skills`
  - 用于参考 catalog 结构和技能元数据组织方式
- `skills.sh` / Vercel Skills
  - 用于二期做“远端搜索入口”和“一键导入来源”
- `awesomeAgentskills`
  - 用于整理可接入的高质量公开 skill 源

如果你说的 `find-skills` 是 Vercel skills 生态里的搜索 skill，那么它更适合放在“二期外部搜索”里，而不是当前 MVP 的核心依赖。

## 当前开发顺序

### Phase 1: 本地管理器

1. 修复预览稳定性，保证 `3009` 可访问
2. 做干净的 `Claude / Codex` 双栏管理
3. 打磨搜索、排序、分页和详情预览
4. 打通删除和跨库同步

### Phase 2: 同步与更新

1. 建立本地与 GitHub 镜像的差异模型
2. 做同步矩阵和更新提示
3. 增强 GitHub fetch / pull / push 反馈
4. 增加定期更新检查入口

### Phase 3: Docker 与开源

1. 容器挂载本地 skills 目录
2. 做一键启动和环境说明
3. 抽掉个人路径和个人仓库耦合
4. 补开源文档、示意图和测试
