# Everyday Insight

当题目不是宏大趋势，而是一个看似很小、很日常、很互联网的现象时，用这份参考校准。

## 什么时候读

- 题目来自刷屏测试、梗图、群聊、校园日常、社交动作、流行说法
- 用户明确说“从小事里洞察”“互联网文化观察”“这种现象为什么会火”
- 你已经感觉到这个题目表面很轻，但背后其实有稳定结构

## 核心要求

不要把这类题目写成：

- 热点复述
- 单纯吐槽
- “年轻人又在玩抽象”的感想
- 只有现象，没有结构的碎观察

要把它写成：

- 一个日常触发点
- 一层更深的传播 / 产品 / 人性 / 关系结构
- 一个读者能带走的具体判断

## 推荐写法

1. 先承认它表面上的轻和怪，不要假装它天生宏大。
2. 再说明你为什么不想轻视它。
3. 往下拆：到底是哪层结构让它成立。
4. 抽出 1-3 个判断。
5. 最后用一句“更具体的提醒”收住。

## SBTI 文章校准片段

这些句子来自 SBTI 文章，适合拿来感受这种题材该怎么写。

### 开头判断

- 很多看起来荒诞、无厘头、甚至上不了台面的互联网小狂欢，背后其实都藏着非常稳定的传播逻辑。
- 对做内容的人、做产品的人、关心用户的人来说，这种东西反而很值得拆。

### 中段拆法

- 它借了 MBTI 的结构壳，套了中文互联网的抽象梗，混进了英文缩写的熟悉感，再把“看别人”和“被别人看”这套社交欲望一起点燃。
- 它不是在输出信息，而是在制造互动理由。
- 真正被消费的，不是“答案”，而是“答案带来的社交空间”。

### 结尾钉子句

- 而是一个更具体的提醒：互联网里最强的传播，很多时候都不是在说服你，而是在邀请你参与定义自己。

## 结尾禁忌

当你已经写出“钉子句”之后，就应该停。

不要再接：

- 这也是我最近越来越有感觉的一件事。
- 如果你最近也关注这些东西，欢迎和我交流。
- 这样的现象，我之后应该还会继续写。
