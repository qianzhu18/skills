# Style Guide

## 总体方向

这套长文风格的关键词是：

- 第一人称强
- 句子短
- 判断准
- 有上升感
- 像朋友聊天

如果一段话读起来很正确，但不像一个真实的年轻人在说话，就继续改。

## 基本语气

### 1. 我必须在场

- 不要把文章写成无人称说明书
- 先讲我为什么写、我卡在哪、我怎么想明白
- 再进入概念和判断

### 2. 要锋利，但不要油

- 句子可以短
- 结论可以干脆
- 但不要为了有气势而硬写狠话

### 3. 像聊天，不像讲课

- 读感像和朋友认真聊一件重要的事
- 不是上价值
- 不是灌鸡汤
- 也不是课堂板书

## 长文默认结构

适合学习拆解型、认知更新型公众号长文。

### 1. 开头

- 从一个真实的卡点、困惑、触发时刻切入
- 第一屏就告诉读者，这篇为什么值得读
- 优先使用：
  - 我以前一直没想明白……
  - 我这次终于想通了一件事……
  - 这一章我卡了很久……

### 2. 主体

- 每一节只推进一个判断
- 先人话，再术语
- 先感觉，再原理
- 先解释为什么这件事重要，再解释它是什么

### 3. 结尾

- 回到“我现在真正建立起来的理解”
- 留一句可以被单独转发的判断
- 不要硬喊口号

## 句子规则

1. 一段尽量 1-4 句。
2. 一句里尽量只做一件事。
3. 抽象词太多时，补一个具体动作或场景。
4. 能用短句就不用长从句。
5. 第一人称后面必须跟观察、感受或判断，不要空转。

## 适合 qianzhu 的长文原型

### A. 学习拆解型

适合技术基础、知识梳理、概念重写。

结构：

- 我为什么卡住
- 我把哪条线连起来了
- 分 3-7 段讲清
- 最后留下 3-7 个判断

### B. 实践记录型

适合模型实验、工作流、项目尝试。

结构：

- 我在做什么
- 我怎么跑了一遍
- 我撞到了什么边界
- 这次真正学到的是什么

### C. 认知更新型

适合对一个热门概念重新理解。

结构：

- 我原来怎么想
- 我后来为什么改观
- 改观后的新理解是什么

## 语言手感

优先写成这样：

- 我以前一直把这件事想反了
- 到这里我才真的通了
- 它不是……它更像……
- 这件事一旦放回真实使用里看
- 我现在更愿意把它理解成……

少写成这样：

- 本质上
- 换句话说
- 这意味着
- 值得注意的是
- 不难发现
- 首先 / 其次 / 最后

也少用：

- 过量感叹号
- 过量网络梗
- 过量“兄弟们”“家人们”式口癖
- 过量装成熟的行业黑话

## 标题规则

标题优先级：

1. 第一人称突破感
2. 认知反转
3. 明确主题词
4. 不夸张，但要有点击理由

优先使用的结构：

- 我 + 重学 / 终于看懂 / 终于讲顺 + 主题
- 一个反常识判断 + 为什么
- 我把最难的一章 / 最绕的一块 + 重写成了什么

## 100 字导流文案规则

- 每条约 100 字
- 不能只是摘要
- 重点写：
  - 这篇讲了什么
  - 谁适合看
  - 为什么现在值得点开

## 全链路输出要求

每次跑这套 skill，默认同时产出：

1. `公众号/源稿.md`
2. `title/公众号-爆款标题候选.md`
3. `title/短信息流安利文案.md`

如果用户没有明确说不要图，就保留可插图结构。

## 最后检查

交稿前至少问自己这 5 句：

1. 这一版像不像一个真正的大学生 AI native 在说话？
2. 我是不是把自己写没了？
3. 这篇是讲顺了，还是只是讲全了？
4. 有没有一句让我自己都愿意单独发出来？
5. 有没有哪一段太像老师、太像公司、太不像我？
