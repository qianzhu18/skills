# Audience

核心句先记住：

我写给想用 AI 提升自己、也愿意看一个年轻实践者持续成长的人。

这份 audience 约束，是这次 skill 里新增的关键层。以后写作时，不要只想着给“找工具的人”和“看趋势的人”看，还要给那些愿意观察一个普通年轻人如何在 AI 时代一点点长出来的人看。

## 四类核心读者

### 1. 工具与工作流导向读者

- 对 AI 工具、开源项目、效率工具、自动化工作流感兴趣
- 期待少踩坑，想知道什么值得试，什么真的能提升效率
- 喜欢“我试过了，所以我告诉你哪里有用、哪里别浪费时间”

### 2. 刚起步的实践者

- 刚开始接触 AI 产品、技术实践、个人搭建
- 不一定已经很强，但愿意看一个真实的人如何理解问题、试工具、形成方法
- 他们不只要答案，也在看“这个人是怎么想明白的”

### 3. 同阶段的年轻人

- 和作者处在相近的人生阶段，普通背景，仍在摸索路径
- 既关心 AI，也关心一个人如何在信息很多、机会很多、焦虑也很多的环境里慢慢找到自己的位置
- 他们会对“我离他不远”有很强感受

### 4. 成长观察型读者

- 不一定会完全复刻作者路径
- 但愿意长期看一个人持续记录、持续试错、持续变清楚
- 他们会因为成长感留下来，不只是因为某篇文章的信息量

## 读者为什么会继续看

他们留下来，通常不是只因为某一个工具推荐。

他们是在同时获得三样东西：

- 实用信息，知道什么值得上手
- 个人判断，知道作者怎么看而不是只转资料
- 成长陪伴，看到一个普通年轻人如何一点点建立能力和表达

## 每篇文章都要回答的两个问题

1. 这篇主要写给哪一类人看？
2. 这篇里哪一句或哪一段，会让读者感到“原来普通人也可以一点点长出来”？

如果两个问题都答不上来，这篇通常会滑向两种坏结果：

- 只剩信息，没有人
- 只剩情绪，没有方法

## 选题对位法

写之前，先做一个简版判断：

- `主读者`：谁会第一时间点开、收藏、转发？
- `次读者`：谁不一定立刻用上，但会因为作者本人的路径继续关注？

常见搭配：

- 工具/开源推荐：主读者是 1，次读者是 2 或 3
- 工作流/方法：主读者是 1 或 2，次读者是 3
- 趋势观察：主读者是 1 或 2，次读者是 3 或 4
- 成长记录：主读者是 3 或 4，次读者是 2

## 不要误判的点

- 不要把读者想成一群已经很成熟的从业者
- 不要默认大家只是来拿工具链接
- 不要把“成长感”写成励志鸡汤
- 不要为了讨好成长观察型读者，把文章写成纯日记

成长感最好的状态是：

内容有用，人也是真的。
